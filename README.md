## ✈️ Flight Radar

Flight Radar projesi, React ve Axios kullanılarak geliştirilmiş, uçuşları harita üzerinde görüntülemeyi ve uçuş detaylarını incelemeyi sağlayan responsive bir web uygulamasıdır. Leaflet ile interaktif harita deneyimi sunan proje, kullanıcıların uçuş bilgilerine kolayca erişmesini amaçlar.

## ✨ Özellikler

🗺️ Uçuşları interaktif harita üzerinde görüntüleme

📍 Harita üzerindeki uçuş işaretçileriyle etkileşim

🔎 Uçuş detaylarını görüntüleme

📋 Liste ve harita görünümleri arasında gezinme

📱 Farklı ekran boyutlarına uyum sağlayan responsive tasarım

🔄 Axios ile API üzerinden veri alma

⚡ Redux Toolkit ve React Redux ile state yönetimi

## 🛠️ Kullanılan Teknolojiler

React · React Router DOM · React Redux · Redux Toolkit · Splide.js · Leaflet · Axios · Bootstrap
